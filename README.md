# ctfwriteupmapper
A helpful database connecting methodologies
Have you ever done a CTF challenge but had to search through multiple manuals in order to follow the steps for the writeup? Frustrated that you can't get an exact guide of where you are to solving the challenge? This database hopefully helps in getting people from whatever skill level they are and tools they know, anywhere from zero to solving it!
pls feel free to contribute! anything would help! Please write nice code and document so other people can use your code as well!
